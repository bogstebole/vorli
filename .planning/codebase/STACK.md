# Technology Stack

**Analysis Date:** 2026-03-12

## Languages

**Primary:**
- Swift 5.x (Xcode 26.2 toolchain) - All application source code

**Secondary:**
- None — pure Swift project

## Runtime

**Environment:**
- iOS 26.2 (deployment target: `IPHONEOS_DEPLOYMENT_TARGET = 26.2` in `Receipt Tracker.xcodeproj/project.pbxproj`)
- iPhone and iPad supported

**Package Manager:**
- Swift Package Manager (SPM) — integrated via Xcode
- No `Package.swift` manifest; dependencies declared in `project.pbxproj` as `XCRemoteSwiftPackageReference`

## Frameworks

**Core UI:**
- SwiftUI — all views (`ContentView.swift`, `VorliChatView.swift`, `QRScannerView.swift`, etc.)

**Persistence:**
- SwiftData — local on-device database
  - Config: `Receipt_TrackerApp.swift` (`ModelContainer` with `isStoredInMemoryOnly: false`)
  - Models: `Receipt`, `ReceiptItem`, `Budget`, `BudgetEntry` (all in `Receipt Tracker/Receipt.swift`)

**Camera & Scanning:**
- AVFoundation — live camera feed for QR code scanning (`QRScannerView.swift`)
- PhotosUI — `PhotosPickerItem` for photo library image selection (`QRScannerView.swift`)

**OCR:**
- Vision framework — `VNRecognizeTextRequest` for on-device text recognition from receipt images (`ReceiptOCRParser.swift` in project root)

**Authentication (inactive):**
- FirebaseAuth — imported via SPM; entire implementation is commented out for v1 release (`AuthenticationManager.swift`)
- AuthenticationServices — Apple Sign In support (commented out)
- CryptoKit — nonce SHA-256 for Apple Sign In (commented out)

**Observability:**
- `@Observable` macro (Swift Observation framework, iOS 17+) — used in `AuthenticationManager` (commented out)

**Build/Dev:**
- Xcode 26.2 (`LastUpgradeCheck = 2620` in `project.pbxproj`)
- Swift Approachable Concurrency enabled (`SWIFT_APPROACHABLE_CONCURRENCY = YES`)
- Default actor isolation set to `@MainActor` (`SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`)

## Key Dependencies

**Critical:**
- `firebase-ios-sdk` (via SPM remote reference) — provides `FirebaseCore`, `FirebaseAuth`, `FirebaseFirestore`
  - Firebase is initialized at app launch even though auth is disabled: `FirebaseApp.configure()` in `AppDelegate`
  - Firestore is linked as a framework but has no active usage in app code

**Infrastructure:**
- No third-party networking libraries — all HTTP via `URLSession` directly
- No third-party JSON libraries — `JSONEncoder`/`JSONDecoder` from Foundation

## Configuration

**Environment:**
- No `.env` files — Anthropic API key is stored at runtime in `UserDefaults` under key `"vorli_anthropic_api_key"`
- Firebase configuration: `GoogleService-Info.plist` (committed to repo, contains Firebase project `receipt-tracker-96a3d`)
- User profile persisted in `UserDefaults` with prefix `"vorli_profile_"` (keys: `prihod`, `budzet`, `cilj`)

**Build:**
- `Receipt Tracker.xcodeproj/project.pbxproj` — single Xcode project, no workspace
- `Receipt-Tracker-Info.plist` — empty plist (Info.plist keys generated by Xcode build system)
- `Receipt Tracker/Receipt Tracker.entitlements` — Apple Sign In capability declared
- Bundle ID: `bogste.Receipt-Tracker`
- Development Team: `QLXB6T6X9W`

## Platform Requirements

**Development:**
- macOS with Xcode 26.2
- Apple Developer account (QLXB6T6X9W) for code signing

**Production:**
- iOS 26.2+ (iPhone primary, iPad supported)
- App Store distribution (standard iOS)
- Camera permission required: `NSCameraUsageDescription = "We need camera access to scan receipt QR codes"`
