## Naming Conventions

- **Views**: `[Feature]View.swift` or `[Feature]Sheet.swift` for modal sheets
- **Services**: `[Domain]Service.swift`
- **Models**: Noun only (`Receipt.swift`, not `ReceiptModel.swift`)
- **Parsers**: `[Domain]Parser.swift`
- **ViewModels**: `[Feature]ViewModel.swift`
- **Debug views**: `[Feature]DebugView.swift` or `[Feature]TestView.swift`

## Notable Structural Issue

Several view files (`AddNewSheet`, `DashboardSheet`, `ReceiptCardView`, etc.) and `ReceiptOCRParser` sit at the project root rather than inside the `Receipt Tracker/` target group. This is an Xcode project organization inconsistency — all files are in the same build target but the file system layout is split.
