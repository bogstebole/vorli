3. Inside `build()`, after the existing `dict` is constructed, add the `finansije` section. Inject it only when at least one data source is available (budget or profile income > 0):

```swift
// Add finansije block if budget or income data is available
if budget != nil || (userProfile?.mesecniPrihod ?? 0) > 0 {
    var finansijeDict: [String: Any] = [:]

    if let budget {
        finansijeDict["stanje"] = Double(truncating: budget.currentBalance as NSDecimalNumber)
        finansijeDict["poslednji_unos"] = dateFormatter.string(from: budget.lastUpdated)
    }

    if let profile = userProfile {
        finansijeDict["mesecni_prihod"] = profile.mesecniPrihod
        let parsed = profile.parsedBudzetModel
        finansijeDict["budzet_model"] = [
            "potrebe": parsed.potrebe,
            "zabava": parsed.zabava,
            "stednja": parsed.stednja
        ]
    }

    if !finansijeDict.isEmpty {
        dict["finansije"] = finansijeDict
    }
}
```

Important: Use `[String: Any]` dict construction (matching the existing pattern for `meta` in this file) rather than JSONEncoder on FinansijeJSON — this avoids a second encode/decode round-trip and keeps the style consistent. The `FinansijeJSON` struct can remain as a reference/documentation type but the serialization uses the dict approach.

Do NOT modify the period helper methods or the `encode(_:)` / `toJSONArray(_:)` private methods.
